# 🚀 Odisea Espacial Asteroid

Odisea Espacial Asteroid es una aplicación web moderna desarrollada con **React + Vite**, diseñada para ofrecer una experiencia rápida e interactiva e integrar servicios de IA externos de forma segura mediante variables de entorno.

---

## 🛠️ Herramientas Tecnológica para meter mano 

- ⚛️ React
- ⚡ Vite
- 🟦 TypeScript
- 🤖 API GenAI de Google
- 📦 Node.js y npm

---
